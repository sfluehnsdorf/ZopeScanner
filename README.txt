Products.ZopeScanner
====================


This is an unreleased Product for the Zope Web Application Server for introspection. It grants insight into the inner workings of the Zope Server. It's intended use is for development, debugging and forensic analysis. It installs itself into the server's Control Panel and is removed completely by uninstalling the package.

Tested to work with Zope releases 6.1, 5.14.2, 4.8.11 (Python 3 and 2), and 2.13.30.
